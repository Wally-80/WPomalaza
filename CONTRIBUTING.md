# Contributing to WPomalaza

## Branching Strategy
- `main`: Production-ready code.
- `feature/*`: New features and enhancements.
- `bugfix/*`: Critical fixes.

## Local Setup
1. Clone the repo.
2. Run `npm install`.
3. Set up `.env.local` with Firebase credentials.
4. Run `npm run dev`.

## PR Rules
- Ensure all logic is covered by TypeScript types.
- Maintain the "Premium Identity" aesthetic in all UI components.
- Test responsiveness on mobile before merging.
